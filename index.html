Questions.

Is this an IDE?

No. Keep the editor you use. An editor shows one file at a time and an agent panel one message at a time; Bluprint shows how the whole repository fits together and what a change did to it. It opens the code where you need it, and hands your questions to the agent beside it.

Does my code leave my computer?

Only the way it does whenever you use Claude Code: your own Claude Code reads the files it needs to make the map. The map itself is saved on your computer and nowhere else.

What do I need?

A Mac or a Linux desktop, and Claude Code signed in with a Claude plan. Making a map counts against that plan's usage, like any other Claude Code session.

Which languages does it read?

TypeScript, JavaScript, Python, Go, Ruby, Rust, Java, Kotlin, Scala, Swift, PHP, C# and Elixir, along with Vue, Svelte and Astro components, and the SQL, Prisma, GraphQL and protobuf files around them.

How do I tell what's proven from what's a guess?

A solid line or a plain card came from the code. Anything the map couldn't prove is marked: a dashed line, or a card labelled partial or inferred. Sentences that failed the check are taken out before you see them.

What happens when the code changes?

An update finds the files that changed since the map last looked, redoes only the sections whose code they touch, and moves every other line reference along with the code, so the rest stays true.
